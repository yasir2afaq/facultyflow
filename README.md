# FacultyFlow — SRM University-AP

A phone-first Progressive Web App for faculty timetable management, live lecture tracking, adjustment classes, and semester teaching analytics.

## Features
- Today's classes shown immediately on opening
- SRM University-AP branding and faculty profile
- University → School → Department → Faculty structure
- Timetable import via CSV/TXT with preview/replacement
- Regular + adjustment classes
- Start Lecture → live countdown → Mark Complete
- Actual teaching time calculated from start to completion
- Semester tracker: lectures, actual time, planned time, completion, recent and course-wise history
- CSV semester export
- Faculty photo profile
- Local device storage and PWA support

## GitHub Pages
Upload all files in this folder to the repository root, then enable GitHub Pages from `main` / root.

## CSV format
`Day,Start,End,Course,Section,Room,Type`

Example:
`Wednesday,11:00,11:50,CSE 101,CS I-C,V101,Regular Class`
